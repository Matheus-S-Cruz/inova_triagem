# Triagem+

Projeto React + Vite + Tailwind CSS.

## Servidor de desenvolvimento

```bash
npm install
npm run dev
```

O app fica disponível em `http://localhost:8443`.

## Arquivos principais

- `src/App.tsx` — componente principal / roteamento por hash
- `src/main.tsx` — entry point do React
- `src/index.css` — estilos globais e import do Tailwind
- `package.json` — dependências e scripts
- `vite.config.ts` — configuração do Vite

## Estilização

Tailwind CSS v4, via plugin do Vite (sem PostCSS separado).
